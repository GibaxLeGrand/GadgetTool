## RESUME POINT: the final test (Gibax's OK for each step)

The final test is the whole chain on the real save, by Gibax or with his OK:

1. Game closed (and Steam Cloud left alone: GadgetTool backs the save up first, into
   `%LOCALAPPDATA%\GadgetTool\Backups`).
2. Launch the app by double-clicking `extracted\lancer_gadgettool.cmd` (not from Claude: the
   Claude app redirects what its own processes write in `%APPDATA%`, so the game would not
   see the save). It runs the Release build with
   `--data extracted\pack --save-key extracted\save_key.local.txt`; build it first from the
   newest branch (`dotnet build GadgetTool.slnx -c Release`).
3. Open the save (the dialog starts in the game's save folder), check P1's presets look as
   in the game (names, icons, Super Slot).
4. Change one preset of P1 that is not used much (for example J): another gadget, or the
   Super Slot. Save. Note the backup's path.
5. Launch the game, open the gadget plate: the preset must show the change, the others
   unchanged, nothing else lost (progress, unlocks, karts).
6. If anything is wrong: game closed, copy the backup back over `app.sav`.

After that: the key question for the public release (advice: in the data packs on the
releases page, never in git), `index.json`, the Super effects and category colours in the
page, then a first release.
