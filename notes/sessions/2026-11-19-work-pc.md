## What was built

- **Core** (`src/GadgetTool.Core`, .NET 10, no UI): plate rules (two rows of 3 + Super Slot,
  1/2/3-slot gadgets that never span rows), copy/paste on many presets (strict or "leave out
  what a player cannot use"), share codes `GT1-…`, `.gtpresets` files, a stand-in save
  format (`DevJsonSaveFormat`), safe writing (game closed, file unchanged since read,
  timestamped backup in LocalAppData, temp file), `SaveSession` (only plates change),
  preset names (tool only), game versions in shares and saves, game texts in several
  languages, and `AppBridge` (the JSON messages the page sends).
- **App** (`src/GadgetTool.App`): WinForms window, the page in WebView2 under
  `https://gadgettool.example/`, Windows file dialogs, game detection by process name
  (guessed names), asks before closing with unsaved presets. Run it with
  `dotnet run --project src/GadgetTool.App` (`--catalog <file>`, `--dev`).
- **Web** (`web/`): Lists view (default) and Game style view; colours as a separate setting
  (per view / dark / the game's); preset names; Import next to Share; game-version checks on
  import; game-update banner on open; language picker for the game's texts. In a plain
  browser it runs on a stand-in host (serve the repo root with
  `python -m http.server 8766 --bind 127.0.0.1`, open `/web/`).
- **Data** (`data/dev`): made-up catalog (English + French) and sample save. Format for real
  data: `docs/DATA.md`.
