# Notes

What an agent needs to pick the project up on any machine, on the model of padlobby's
`notes/`.

| File | What |
|---|---|
| [memoire-agent.md](memoire-agent.md) | How Gibax works on this project, every decision taken and why, open questions. Read it first. |
| [sessions/](sessions/) | One note per working session: what was done, what was seen, where to resume. The last one holds the resume point. |

Order to read when resuming: this file, `memoire-agent.md`, then the last note in `sessions/`.

Rules for these files: written in English like everything in git; a session note is added at
the end of each session; `memoire-agent.md` is kept current (decisions are added with their
date, not rewritten away).

**This repository is public.** Keep these notes technical: nothing personal about Gibax, no
paths with user names, no Steam IDs, no save contents. Personal working rules stay in each
machine's agent memory or in a private place.
